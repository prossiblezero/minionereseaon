# 简历与面试材料

**MiniOneReason：生成式推荐的推理成本与后训练实验**

- 基于 OneReason-0.8B 和公开商品推荐样本，完成 LoRA SFT、seed 42 的四种 RL 对照及历史选择消融；主要训练使用 RTX 4090，后续评测迁移至 RTX 5090。
- 建立固定 32/64 次生成尝试的 SID 评测，记录无效输出、重复率和 token 成本，用配对 bootstrap 检查收益的不确定性，所有结果可追溯至适配器和原始预测。
- 测试集 403 条，seed 42 的 Recall@32：直接 SFT 2.730%；混合 SFT 不思考 1.985%；混合 SFT 思考 2.233%。
- 实现 N×K=4×8 分支采样和三级 SID 前缀奖励，并保留 GRPO-8、GRPO-32 与无前缀 N×K 对照；前缀奖励模型的本地测试 Recall@32 为 4.467%，相对混合 SFT 思考模式提高 2.233 个百分点，配对 bootstrap 95% 区间为 [0.478, 4.082] 个百分点。
- 完成官方 v3.1 商品任务的 1,000 条外部评测：本项目 0.8B RL 模型的真实商品 ID Recall@64 为 2.002%，Pass@64 为 3.100%；使用官方 Race 32+32 候选和评分程序。

统计范围：单次 seed 42。主线成绩使用分组留出的单目标 SID 指标，官方商品任务单独在商品 ID 上计分。多种子稳定性和线上收益尚未验证。

面试重点：混合 SFT 与 RFT 的区别；32 答案 GRPO 对照与 N×K 信用分配；前缀奖励如何增加组内差异；固定尝试次数与 token 成本的区别；SID 碰撞如何造成 SID 和真实商品 ID 成绩差距；随机路由对照、历史消融和 SASRec 全零的解释。
